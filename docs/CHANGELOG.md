# Changelog

All notable changes to this project will be documented in this file.

## [v1.0.0] - 2026-05-03

### Added

- **Stop Hook** - Session结束时提炼记忆
- **SessionStart Hook** - 启动时注入相关记忆
- **Verifier Judge** - 四维质量门控
- **Knowledge Store** - JSONL 持久化存储
- **Git Sync** - 多设备同步
- **CLI** - `myteambrain` 命令行工具
- **Setup** - 一键安装脚本

### Features

- Memory lifecycle management via hooks
- Multi-device synchronization through Git remotes
- Quality gate verification with verifier-judge
- JSONL-based knowledge persistence
- Command-line interface for team brain operations
